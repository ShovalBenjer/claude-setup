## Key Discoveries

1. **Azure AI Content Safety filter refusals are stochastic (~20% rate)**: Same financial query passes 8/10 times. Refusal text is always in English regardless of agent language. Two patterns: full refusal (<200 chars) and mid-response cutoff (last 100 chars of longer response).

2. **Refusal-retry eliminates the problem**: Exponential backoff retry (up to 4 attempts) reduces effective refusal rate from ~20% to 0%. Validated with 10-run test (3 catches) and 4-test gate (4/4 passed).

3. **Portal content safety config needed**: Default `Microsoft.DefaultV2` policy uses Medium threshold. Financial terms like "loss", "risk", "margin call" can trigger at medium sensitivity. Fix: create content filter with High threshold, assign as guardrail.

4. **pytest exit 0 on all-skipped**: When env var missing, all tests skip but exit code is 0. Must verify passed+failed > 0.
