## Key Finding: No Programmatic API for AI Foundry Applications

Azure AI Foundry "applications" (the agent type used by Seekapa/AxiaCS) cannot be updated via API:
- PATCH → 405
- PUT → UnsupportedApiVersion
- GET config → "API operation not supported for token authentication"
- azure-ai-projects SDK v2.0.0b2 has no management methods
- **Portal-only configuration**
