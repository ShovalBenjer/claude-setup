## Architecture Summary

```
Parent App (Web/Mobile) ──────┐
                              │
                              ▼
                   /api/generate-signed-link
                              │
                              ▼
                       Signed Token
                   (login_timestamp_signature)
                              │
    ┌─────────────────────────┼─────────────────────────┐
    ▼                         ▼                         ▼
Web Widget              Telegram Bot             WhatsApp Bot
(postMessage)           (/start token)           (deep link)
    │                         │                         │
    └─────────────────────────┼─────────────────────────┘
                              │
                              ▼
                     /api/validate-token
                              │
                              ▼
                   CS Agent (session-locked)
                              │
                              ▼
                       CRM Data Access
```

### Token Format
```
{login}_{timestamp}_{signature}
Example: 5844134_1737190920_abc123def456
```

### Security Model
- HMAC-SHA256 prevents login ID guessing
- 24-hour default expiration
- Brand-scoped (Seekapa token ≠ Axia token)
- Session locking prevents cross-user data access
