# Documentation control

Separate current state, proposed design, historical evidence, and generated output.
Date drift-prone claims and link to their source. Do not turn a plan into a claim
that code, deployment, or production behavior exists. Keep one authoritative
location per fact and update indexes only after the underlying evidence changes.
