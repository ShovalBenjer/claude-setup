# Multi-agent workflows

Delegate independent, bounded work with compact context packets. Give each worker
exclusive write scope or make it read-only. Use a separate evaluator for high-risk
claims, reconcile conflicting findings, and verify the assembled final state.
Choose models per task and current availability; do not encode obsolete model IDs.
