What the AI never does on its own

  • Reads. Pulls. Summarizes. Compares.
  • Sends WhatsApp / email / push. Touches a CRM record. Initiates a refund. Anything with side-effects.
  • Any of the right-column actions ↑ require human approval first — funnel-ui ships with an approval gate that pauses the agent before any write.

CRM — Customer record + cohort
Live · Read-only · Source: Seekapa CRM (Amit's read endpoint)
3 tools

Pulls customer data the same way Sales / Retention sees it in the CRM UI — but in a shape the agent can analyse. No writes. The summary tool masks PII (email, phone, full name) by default; raw fields come through only when the agent has explicit elevated scope.

crm_get_customer
Full raw CRM record for one account.
When to use: deep dive on a single lead — full deposit history, every comment, every flag.
"Show me everything CRM has on ACC30245740."
crm_get_customer_cohort
Same as above but for up to 20 accounts at once.
When to use: comparing a small group — e.g. a campaign cohort, this week's FTDs, a specific country slice.
"Compare the 18 Saudi FTDs from the May 5–12 push."
crm_get_customer_summary
Executive-view summary: deposits, last activity, status, classified comments. PII redacted.
When to use: most common CRM read — the agent's default when you ask "what's going on with X."
"Give me the one-page on ACC30184902."

Call Analyzer — VoIP calls, CDRs, transcripts
Live · Source: analyzer.corp-domain.com (Yasha's call quality service)
6 tools

The Sales team's call recordings — fetched, transcribed (ElevenLabs Scribe, 89% accurate on Arabic), then made readable to the agent. Underpins the "did the rep follow script?" and "what did the customer object to?" questions.

call_analyzer_get_calls
List of calls for one account: who, when, how long, inbound/outbound.
When to use: "did anyone call this lead?" / call activity audit.
"All calls on ACC30245740 in the last 30 days."
call_analyzer_get_cdr
Call Detail Record — raw VoIP metadata (provider, realm, queue).
When to use: diagnosing routing or queue issues — mostly engineering.
(Internal — rarely user-facing)
call_analyzer_transcribe_call
Triggers transcription on a recording (or returns one if already done).
When to use: only 13% of calls are pre-transcribed; this is how the agent gets the rest.
(Triggered automatically by the agent — rarely asked for by name)
call_analyzer_get_transcript
Compact transcript: language + speaker-tagged segments. ≤6 KB.
When to use: agent reads this to summarize "what happened on the call."
"What did Pedro say on the May 7 call about the platform fee?"
call_analyzer_get_transcript_raw
Full ElevenLabs output: every word, timestamps, speaker IDs, confidence scores.
When to use: forensic — quote a customer's exact words, dispute resolution.
"Exact timestamp where the rep mentioned the bonus."
call_analyzer_ensure_transcript
One-call wrapper: trigger + poll + fetch. Returns one of: AVAILABLE / NOT_RECORDED / PENDING / FAILED.
When to use: the agent's default — saves the multi-step dance.
(Internal — the agent picks this 95% of the time)

OneSignal — Push + email history
Live · Read-only · 64,945 notifications across Seekapa + Axia
2 tools

What we've sent to customers via OneSignal — both web push and the email template library. The agent uses this to answer "did we already pitch this person?" and to check messaging consistency.

onesignal_list_notifications
Notification log — what was sent, when, to which segment, open/click rate.
When to use: audit a campaign send; check fatigue ("how many emails this week?").
"All FTD nudges sent to UAE leads in April."
onesignal_view_template
The template content itself — subject, body, language.
When to use: review what an automation actually said before approving a new variant.
"Show me the welcome email Saudi leads get on day 1."

Chatwoot — Live-chat + WhatsApp conversations
Live · PII-masked · Source: Chatwoot (cs-agent's home)
3 tools

The other side of customer contact — chat / WhatsApp that the CS agent handles. PII is masked by default (phone, email blanked); private agent notes are hidden unless explicitly elevated.

chatwoot_list_inboxes
All Chatwoot inboxes + which one is the WhatsApp WAHA channel.
When to use: orientation — "what channels do we have?".
"How many Chatwoot inboxes are connected?"
chatwoot_list_conversations
Conversations in one inbox, filtered by status (open / resolved / pending).
When to use: backlog check; "what's still open in WhatsApp?".
"Open conversations in the Arabic WhatsApp inbox right now."
chatwoot_get_conversation_messages
Full message thread for one conversation. Default PII-masked.
When to use: read the actual exchange — what did the customer ask, what did CS reply.
"What's the back-and-forth on conversation #4127?"

Analysis — Grading, journey, funnel, comments
Live · Pure logic · No external calls — scores what the other tools pulled
4 tools

These four don't fetch anything. They take what the CRM / Call / OneSignal tools already pulled and turn it into a score, a verdict, or a funnel breakdown. Deterministic — same input always gives same output, so it's auditable.

rubric_grade_call
Scores one call against the 15-layer call-quality rubric (greeting, identification, objection handling, compliance, etc.).
When to use: replaces the old "GPT writes prose then we hope it's consistent" approach. Now: deterministic scores.
"Grade the May 7 call with rep ahmed_b."
compute_journey_verdict
Classifies a customer journey as one of: CONFIRMED / DISCREPANCY / UNVERIFIABLE / OPTIMISTIC / PESSIMISTIC.
When to use: "does the agent's read of this lead match the CRM?". CONFIRMED = aligned; DISCREPANCY = AI and CRM disagree — investigate.
"Journey verdict for ACC30184902."
funnel_aggregate
Builds the full funnel: Impression → Lead → FTD → QFTD → Active, with spend/revenue/ROAS and leakage points.
When to use: top-of-funnel views — "where are we losing people?".
"Funnel for Saudi Brand-RDG_BR in May."
comment_classifier
Classifies CRM comments into types: welcome / pitch / rejection / objection / promise / fact / recycle_note + compliance flags.
When to use: when raw CRM comments are too messy to read — turn them into tags.
"What's the breakdown of comment types on this cohort?"

windsor_list_connectors
Which ad platforms are connected and active.

Verdict family — One opinion per lead, composed live
Live · Composes CRM + calls + grade + journey verdict on every call · 1-hour cache
6 tools

The newest surface (shipped this week, PR #259). These are the "what should we do with this lead?" tools. Live composition means they don't read a pre-baked file — they run the analysis fresh each time using the latest CRM + call data. Output aligned with the CJA v2.1 spec: scores in 90/80/70/60/0 bands; treatment is one of Fast Track / Standard / Nurture / Drop.

get_lead_verdict
One-line answer for one lead: action + score + score band.
When to use: quick triage — "what should the team do with this lead?".
"Verdict on ACC30245740." → Fast Track · 87 (B)
explain_lead
Long-form: why this action / score / band, citing CRM facts + call findings.
When to use: drill-down — "why is this lead a Drop and not a Nurture?".
"Explain the verdict for ACC30184902 in detail."
compare_with_crm
Side-by-side: what the AI thinks vs what CRM says (status, deposit, activity).
When to use: "is the AI making this up or is CRM stale?". Surfaces the gap.
"Compare AI vs CRM for ACC30245740."
verdict_provenance
Audit trail: which data points + which rules produced this verdict.
When to use: compliance / governance — "show me your work".
"Provenance for the verdict on ACC30184902."
list_leads_by_action
Fan out over a list of accounts → filter to "show me only the Fast Track ones".
When to use: building a working list — "give me everyone who's Fast Track this week".
"List Fast Track leads from the May 5-12 Saudi cohort."
list_divergences
Surface the cases where AI says Drop / Nurture but CRM shows the account is still active.
When to use: weekly review — "where are we and CRM disagreeing?". High-signal list.
"Show me divergences across this week's FTD cohort."

Batch — Cohorts >20 accounts
Live · Routes to Azure OpenAI Global Batch (~10× cheaper than live calls)
1 tool

For anything bigger than 20 leads at once, this tool ships the job to Azure OpenAI's overnight Batch API. Cheaper per token, but answers come back hours later — not real-time. Used by engineering for the Liron-grade reports (50–700+ leads).

invoke_bulk_score
Submits a big cohort scoring job; tracks status; pulls results when ready.
When to use: the 738-row Taboola batch and similar weekly reports.
"Bulk score the May Taboola cohort."

BI-collision guardrail
Owner directive 2026-05-10 · "I don't want at all collision with BI"
  • All industry benchmarks stripped — the agent will not publish a number that Power BI computes differently.
  • Score bands aligned to CJA v2.1 §8.2: 90+ A, 80-89 B, 70-79 C, 60-69 D, <60 F.
  • Treatment vocabulary aligned to §12.2: Fast Track / Standard / Nurture / Drop.
  • No leakage flags or "good vs excellent" judgements baked in. BI owns those.

If you see the agent publish a number that contradicts BI, that's a bug — please flag it and we'll fix it before BI sees a contradicting report.
