Foundry agent + dedup

Azure AI Foundry call pattern

  • POST {endpoint}/applications/{agent}/protocols/openai/responses
  • Body: {"input": [{"role":"user","content":"..."}]}
  • Auth: api-key header (key mode) or Bearer (OIDC)
  • Seekapa: KB only. AxiaCS: KB + full CRM OpenAPI suite
  • Content safety refusals: retry up to 5× (20% rate)

Deduplication (prevents triple responses)

  • Chatwoot: key = payload["id"], TTL 300s, also checks if bot already replied
  • Telegram: key = update["update_id"], TTL 120s
  • Why: Chatwoot retries on slow responses; without dedup each retry spawns a new agent call
  • Always return HTTP 200 to Telegram to prevent infinite retries

Dual-judge gate

Primary judge — grok-4-1-fast-reasoning-2-eval

  • Checks: route match, required keywords present, forbidden absent
  • Output: {"pass": true, "score": 1, "reason": "..."}
  • Decides pass/fail for CI gate

Audit judge — DeepSeek-V3.2

  • Sees primary result + original exchange independently
  • Output: {"agree": true, "reason": "..."}
  • Runs on first N rows (default 3 in CI, 5 locally)

Run smoke eval locally

# Load key (never echo)
az keyvault secret show --vault-name shoval --name FOUNDRY-API-KEY -o tsv > /tmp/.key

python scripts/foundry_eval_gate.py \
  --dataset tests/test_data/foundry_smoke_eval.jsonl \

CI pipeline stages

5 stages on every push

Stage 1 — Build & Test

Triggers: master · stage · feature/* (azure-function-crm/** changes)
  • uv pip install -r requirements.txt + pip-audit (CVE check)
  • ruff check lint gate → pytest -k "not deepeval" unit tests
  • Produces function-app.zip artifact

Stage 2 — AI Code Review

PR builds only (master / stage targets)
  • checkout: self + persistCredentials: true — required for git diff read
  • Loads FOUNDRY-API-KEY from vault shoval via managecorpairegistry
  • AIPullRequestReviewPrompt@2 — AI reviews the PR diff

Stage 3 — Deploy

After Build passes on master / stage
  • AzureCLI@2 with azureSubscription: managecorpairegistry
  • az functionapp deployment source config-zip -g AZAI_group -n func-cs-agents-dev

Stage 4 — Smoke Tests

Post-deploy, stage branch only
  • Webhook health: dummy payload → expect HTTP 200
  • 3 spec-compliance payloads: KB question + escalation phrase + off-topic guard

Stage 5 — Yasha Eval Gate

Post-deploy, once per stage/master deploy
  • Runs foundry_eval_gate.py on foundry_yasha_eval.jsonl (28 rows)
  • Publishes JUnit XML + Markdown as pipeline artifacts · CI fails on any judge fail
