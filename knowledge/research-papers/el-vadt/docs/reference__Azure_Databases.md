**Azure SQL Family Services**

Azure SQL provides a range of managed cloud database services for migrating, modernizing, and building applications with high compatibility to SQL Server. These prioritized tools emphasize seamless integration within the Azure ecosystem, including portal access for management.[^1][^2]

**Core Azure SQL Offerings**

- **Azure SQL Database**: A fully managed PaaS relational database for high-performance apps, supporting single and elastic pool databases with features like automated backups and zone redundancy. Official docs: https://learn.microsoft.com/en-us/azure/azure-sql/database/[^3][^1]
- **Azure SQL Database Hyperscale**: Scales up to 128 TB with fast backups via storage snapshots, ideal for large databases needing rapid restore and high compute (up to 128 vCores). Official docs: https://learn.microsoft.com/en-us/azure/azure-sql/database/service-tier-hyperscale[^4][^5]
- **Azure SQL Managed Instance**: PaaS with near-100% SQL Server compatibility, native VNet isolation, and features like cross-database queries; supports lift-and-shift migrations. Official docs: https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/sql-managed-instance-paas-overview[^6][^7]
- **SQL Server on Azure Virtual Machines**: IaaS for full SQL Server control on VMs, with Azure Hybrid Benefit for licensing optimization and recent support for managed identities in SQL Server 2022 CU17+. Official docs: https://learn.microsoft.com/en-us/azure/azure-sql/virtual-machines/windows/sql-server-on-azure-vm-iaas-what-is-overview[^8][^9]

**Build New Applications**

- **Azure Cosmos DB**: Globally distributed NoSQL/multi-model database with low-latency SLAs, supporting APIs like SQL, MongoDB, and Cassandra for scalable apps. Official docs: https://learn.microsoft.com/en-us/azure/cosmos-db/[^10]
- **Azure Database for PostgreSQL Flexible Servers**: Managed PostgreSQL with zone-redundant HA, customizable parameters, and burstable compute for dev workloads. Official docs: https://learn.microsoft.com/en-us/azure/postgresql/[^11][^12]

**Modernize Existing Applications**


| Service | Description | Official Reference |
| :-- | :-- | :-- |
| Azure Database for MySQL Flexible Servers | Fully managed MySQL with same-zone/zone-redundant HA, granular config control, and stop/start for cost savings. [^13][^14] | https://learn.microsoft.com/en-us/azure/mysql/flexible-server/overview |
| Azure DocumentDB (MongoDB compatibility) | Cosmos DB MongoDB API for NoSQL workloads with global distribution. [^10] | https://learn.microsoft.com/en-us/azure/cosmos-db/mongodb/introduction |
| Azure Managed Instance for Apache Cassandra | Managed Cassandra-compatible service for wide-column stores. | https://learn.microsoft.com/en-us/azure/cosmos-db/cassandra/introduction |
| MongoDB Atlas (Partner) | Fully managed MongoDB via Azure Marketplace. | https://www.mongodb.com/atlas |
| Neon Serverless Postgres (Partner) | Serverless Postgres with branching, autoscaling compute, and point-in-time recovery. [^15][^16] | https://neon.tech/ |
| Oracle Database@Azure | Exadata in Azure for Oracle workloads. | https://learn.microsoft.com/en-us/azure/oracle/oracle-database-at-azure/overview |

**Hybrid and Additional Services**

- **Azure Arc Data Controllers**: Extend Azure management to on-premises/edge for hybrid SQL/Postgres. Docs: https://learn.microsoft.com/en-us/azure/azure-arc/data/overview
- **Azure Cache for Redis**: In-memory caching for Redis. Docs: https://learn.microsoft.com/en-us/azure/azure-cache-for-redis/
- **Azure Database Migration Service**: Tools for seamless migrations. Docs: https://learn.microsoft.com/en-us/azure/dms/dms-overview

**Key Alternatives**

- **Neon**: Serverless Postgres with git-like branching and edge-optimized drivers.[^15]
- **Supabase**: Postgres-based backend with auto-generated APIs, auth, and real-time.[^17][^18]
- **Upstash**: Serverless Redis, vectors, queues.
- Others like AWS (Aurora Serverless), Turso (SQLite), MotherDuck (DuckDB analytics) offer specialized serverless options outside Azure.
