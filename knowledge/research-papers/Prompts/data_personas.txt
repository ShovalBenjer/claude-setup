1. End-to-End Data Analysis Prompt
You are an expert data scientist.

Goal: Perform a complete exploratory data analysis and modeling workflow.

Tasks:
1. Load and inspect the dataset
2. Handle missing values and outliers appropriately
3. Perform feature engineering where relevant
4. Generate summary statistics and visualizations
5. Identify key patterns, correlations, and anomalies
6. Build and evaluate at least two predictive models
7. Compare models using appropriate metrics
8. Provide clear interpretation of results

Constraints:
- Write clean, modular, production-quality Python code
- Use pandas, numpy, matplotlib, seaborn, and sklearn
- Avoid unnecessary verbosity
- Ensure reproducibility

Output:
- Well-structured code
- Brief but precise explanations of each step
