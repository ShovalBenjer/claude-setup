# Every top-level tracked directory, mapped to the gate domain that exercises
# it or to a stated exemption reason. tools/audit/coverage_map.py check fails
# CLOSED: a top-level directory with no row here (declared covered or
# declared exempt) blocks the gate. This is the opposite default from
# docs/prior-art/out-of-scope.txt (there, an unlisted path is IN scope by
# default); here, an unlisted path is UNKNOWN, and unknown is blocked, not
# silently ungoverned. That inversion is the whole point of this file: it is
# what would have caught dashboard/ automatically the day it was created,
# instead of two days and 39 files later by manual audit.
#
# format: path | covered-by:<gate domain name> | reason
#     or: path | exempt | reason
#
# UNIT: top-level only, not per-subdirectory. dashboard/core, dashboard/web
# and dashboard/src-tauri are three different toolchains under one directory;
# they get one row because the failure mode this file exists to close is "a
# new top-level tree appears with zero domains touching it", not "every
# subdirectory of an already-covered tree is individually accounted for".
# Per-subdirectory tracking is docs/dir-purpose.txt's job (449 rows, already
# maintained by codemap.py) and duplicating that granularity here would be a
# second copy of the same data drifting on its own schedule.
#
# A row's <gate domain name> must be a real domain in quality-contract.json;
# the checker resolves against that file, not just parses this one, so a typo
# here is caught the same run it is written.
