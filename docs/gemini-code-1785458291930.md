### Key Architectural Components

1. **Pre-Code ContractLock (`syn` / `tree-sitter`)**: Enforces JSON/TypeScript/Rust interface signatures *before* code diffs are applied. Rejects context-less diffs.
2. **`RevertSandbox` (Git Worktree Trial Loop)**: Executes agent attempts in isolated `.nexus/sandboxes/` worktrees. Runs self-tests, measures plan divergence, logs post-mortems to `PlanDivergenceDB`, and executes instant `git reset --hard` rollbacks.
3. **Physical Graph Solver (`rapier2d`)**: Nodes exist as physical rigid bodies with collider hulls. Graph edges act as distance joints. Cursor movements inject radial velocity vectors into the simulation world.
4. **Fast-Sim Timeline Player**: Allows frame-by-frame scrubbing of execution steps, AST mutations, and layout metrics without full browser CDP rendering.
5. **GPU Uniform Pipeline (`wgpu` + `bytemuck`)**: Zero-copy transfer of system metrics into WGSL shaders driving procedural Signed Distance Field (SDF) backgrounds.
