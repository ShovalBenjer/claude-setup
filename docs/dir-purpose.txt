# What each directory is for.
#
# Format: path | purpose. One line each. A directory that carries its own
# SKILL.md, README.md, AGENTS.md or CLAUDE.md is documented by that file and must
# NOT appear here: a second copy of a purpose string is the copy that goes stale.
# tools/map/codemap.py check rejects a row beside a self-documenting directory
# (shadow) and a row whose directory is gone (stale), so this file cannot rot
# quietly.
#
# Purposes are written from the files, not from the directory names. Where a tree
# is dead, vendored, or a duplicate, the row says so.
